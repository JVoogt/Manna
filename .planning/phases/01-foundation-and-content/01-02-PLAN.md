  <name>Task 1: Create Multi-Stage Dockerfile</name>
  <files>
    Dockerfile
  </files>
  <action>
    Create a multi-stage Dockerfile optimized for Raspberry Pi (ARM64):

    Stage 1 - Build:
    - FROM node:20-alpine AS build
    - WORKDIR /app
    - Copy package*.json first (layer caching)
    - RUN npm ci (not npm install - faster, deterministic)
    - Copy source files
    - RUN npm run build

    Stage 2 - Production:
    - FROM nginx:alpine
    - Copy dist/ from build stage to /usr/share/nginx/html
    - Copy custom nginx.conf to /etc/nginx/nginx.conf
    - EXPOSE 80
    - No CMD needed (nginx:alpine has default)

    Important:
    - Do NOT use --platform flag in Dockerfile (handled by buildx at build time)
    - Keep layers minimal for faster Pi pulls
    - Set NODE_ENV=production in build stage
  </action>
  <verify>
    Run: docker build -t manna-test .
    Expected: Build completes, image created
  </verify>
  <done>
    Dockerfile produces optimized image with NGINX serving static Astro build. Image size under 50MB.
  </done>

    docker/nginx/nginx.conf
  </files>
  <action>
    Create Docker Compose orchestration with Traefik:

    1. docker/docker-compose.yml:
       Services:
       - traefik:
         - image: traefik:v3.0
         - restart: unless-stopped
         - ports: 80:80, 443:443
         - volumes: docker.sock (read-only), traefik.yml, acme.json
         - environment: CF_DNS_API_TOKEN from .env
         - networks: web
       - manna:
         - build context: .. (parent dir)
         - dockerfile: Dockerfile
         - restart: unless-stopped
         - labels for Traefik:
           - traefik.enable=true
           - traefik.http.routers.manna.rule=Host(`manna.voogt.co.za`)
           - traefik.http.routers.manna.entrypoints=websecure
           - traefik.http.routers.manna.tls.certresolver=letsencrypt
           - traefik.http.services.manna.loadbalancer.server.port=80
         - networks: web
       Networks:
       - web: external: false

    2. docker/traefik/traefik.yml:
       - api.dashboard: false (security)
       - entryPoints:
         - web (80) with HTTP to HTTPS redirect
         - websecure (443)
       - providers.docker.exposedByDefault: false
       - certificatesResolvers.letsencrypt:
         - acme.email: jpvoogt@gmail.com
         - acme.storage: /acme.json
         - acme.dnsChallenge.provider: cloudflare
         - acme.dnsChallenge.delayBeforeCheck: 10s

    3. docker/nginx/nginx.conf:
       - events.worker_connections: 1024
       - gzip on with types (text/plain, css, json, js, xml, svg)
       - gzip_min_length: 1000
       - server listening on 80
       - root: /usr/share/nginx/html
       - Static asset caching: 1 year with "public, immutable"
       - try_files for SPA fallback
       - Security headers: X-Frame-Options, X-Content-Type-Options, X-XSS-Protection

    Create placeholder docker/traefik/acme.json with correct permissions note in comment.
  </action>

    Expected: Valid YAML output, no errors
  </verify>
