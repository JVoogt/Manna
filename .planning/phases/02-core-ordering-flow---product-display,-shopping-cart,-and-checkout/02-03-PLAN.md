Create src/lib/date-utils.ts:
- Define SA_TIMEZONE = 'Africa/Johannesburg'
- Define SA_HOLIDAYS_2026 array (see research doc for dates):
  - 2026-01-01, 2026-04-03, 2026-04-06, 2026-04-27, 2026-05-01
  - 2026-06-16, 2026-08-10, 2026-09-24, 2026-12-16, 2026-12-25
- Export isBusinessDay(date: Date): boolean
  - Returns false for weekends (Saturday/Sunday)
  - Returns false for public holidays
  - Uses date-fns isWeekend and format functions
- Export getMinimumPickupDate(): Date
  - Calculate minimum date as 2 business days from now
  - Loop adding days, counting only business days
  - Return the date after 2 business days have been added
- Export formatSAST(date: Date, formatStr?: string): string
  - Use date-fns-tz formatInTimeZone
  - Default format: 'EEEE, d MMMM yyyy' (e.g., "Thursday, 30 January 2026")

Create src/lib/validators.ts:
- Import z from 'zod'
- Import parsePhoneNumber from 'libphonenumber-js'
- Import date utils
- Export checkoutSchema = z.object({
    name: z.string().min(2, 'Name must be at least 2 characters'),
    phone: z.string().refine(...).transform(...),
    pickupDate: z.date().refine(...),
    notes: z.string().optional()
  })
- Phone validation:
  - Use parsePhoneNumber(val, 'ZA') to parse
  - Check isValid()
  - Transform to E.164 format on success
  - Error message: 'Invalid South African phone number'
- Date validation:
  - Use isBusinessDay to check not weekend/holiday
  - Compare against getMinimumPickupDate()
  - Error message: 'Pickup must be at least 2 business days in advance'
- Export type CheckoutFormData = z.infer<typeof checkoutSchema>
