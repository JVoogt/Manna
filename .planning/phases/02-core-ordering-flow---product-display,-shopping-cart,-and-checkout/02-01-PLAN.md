  <name>Task 2: Create cart types and context with localStorage persistence</name>
  <files>
    - src/types/cart.ts

  </files>
  <action>
Create src/types/cart.ts with CartItem interface:
- id: string (matches product/meal id)
- name: string
- price: number
- quantity: number
- imageUrl?: string (optional)
- type: 'product' | 'meal' (to distinguish item types)

Create src/lib/cart-context.tsx following the separated context pattern from research:
- CartStateContext: holds CartItem[] array
- CartActionsContext: holds { addItem, removeItem, updateQuantity, clearCart }
- CartProvider component wraps both contexts
- Initialize state from localStorage on mount (useEffect, NOT in useState callback to avoid SSR issues)
- Sync state to localStorage on changes (separate useEffect)
- Handle localStorage quota errors gracefully with try/catch
- Memoize actions with useMemo([]) to prevent re-renders
- Export useCartState and useCartActions hooks
- useCartActions throws if used outside provider

Key implementation notes:
- Use `if (typeof window === 'undefined') return []` in initialization to handle SSR
- Use functional updates for all setState calls: `setItems(prev => ...)` to prevent race conditions
- localStorage key: 'manna-cart'
  </action>

  </verify>
